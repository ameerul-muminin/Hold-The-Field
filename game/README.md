# Agrocene: the Java game

Repository: https://github.com/Anthropocene-SpaceApps/Hold-The-Field

A realistic 3D farming game where NASA satellite data is your scout. You walk around Rahim's farm, watch the Satellite
Scout, and decide. Two scenarios: the Sunamganj haor flash flood (raise the bund, harvest early, or let the water take
the rice) and the Barind Tract drought (irrigate from a limited tank before the rice flowers dry out). Same field, same
real weather, replayed day by day. English and Bengali (Options > Language).

Java 21, LWJGL 3 (OpenGL 3.3, GLFW, STB, OpenAL), FlatLaf for the launcher. All textures, models and sounds are generated by code; there are no art files. See [`../docs/GAME_DESIGN.md`](../docs/GAME_DESIGN.md) for how it answers the challenge.

## Run it

Players: download an installer, AppImage or portable build from the GitHub Releases page (no Java needed; see [`../docs/RELEASING.md`](../docs/RELEASING.md)).

Developers: you need Java 21 and a GPU with OpenGL 3.3.

```bash
cd game
mvn package                               # builds target/agrocene.jar (all platforms in one jar)
java -jar target/agrocene.jar       # opens the launcher
```

No display? `java -jar target/agrocene.jar --nogui` starts the game directly.
On macOS the launcher adds `-XstartOnFirstThread` for you. To start the game without the launcher on macOS:
`java -XstartOnFirstThread -cp target/agrocene.jar org.anthropocene.htf.Main`.

### Real NASA data

The repo ships with SAMPLE data so the game always starts (the title screen says so). In the launcher open
**NASA Data** and press **Update NASA data**. It downloads the real season from NASA POWER into
`~/.agrocene/data/` and the game uses it from then on. (The same thing from the command line:
`python3 ../data-pipeline/fetch_power.py ...`, then copy the JSON over `../data/haor-2017.json`.)

## Controls (all rebindable in Options > Controls)

| Key | Action |
|---|---|
| W A S D, Space, Shift, Ctrl | walk, jump, sneak, sprint (double-tap Space to fly) |
| 1 Raise bund / Irrigate | flood: aim at the embankment and click (Tk 40). Drought: aim at the rice field and click (Tk 12 and one tank load) |
| 2 Harvest | aim at the rice and click (from 80% maturity) |
| 3 or **M** | NASA satellite view (drag to look, wheel to zoom, WASD to move) |
| 4 or **E** | scout dashboard with interactive charts |
| Right-click on Rahim | he tells you what the data and the sky are doing |
| P, [ ] | pause or resume time, slower or faster |
| F3, F2, F1, F11 | debug info, screenshot, hide HUD, fullscreen |
| Esc | game menu |

## Layout

```
game/src/main/java/org/anthropocene/htf/
  sim/       pure simulation (planning, water, crop, scout) + season loader
  world/     landscape, atmosphere, farmstead, foliage, Rahim, weather, the scene renderer, player physics
  gfx/       window, shaders, framebuffers, bloom/tonemap post, GUI renderer, fonts, mesh builders
  ui/        title, plan the season, farms, options, key binds, pause, dashboard, charts, debrief, HUD
  game/      main loop, session, saves, advancements, report export, dev capture tool
  audio/     procedural OpenAL sound
  launcher/  Swing launcher and the NASA POWER downloader
  core/      settings, key bindings, I18n (English and Bengali)
game/src/main/resources/shaders/   GLSL: sky, terrain, water, props, rice, rain, post, GUI
game/src/main/resources/lang/bn.txt   Bengali translations (English phrase => Bengali)
packaging/    jpackage installers, AppImage, icons
```

Data lives in the repo's top-level `data/` folder and is bundled into the jar. Player files are in `~/.agrocene`
(options, saves, profile, screenshots, downloaded data); set `-Dhtf.home=DIR` to move them.

## Testing

`mvn test` runs the simulation (both scenarios), planning, data updater, save/replay, landscape, physics, atmosphere and translation tests (no display needed).

### Bengali

Switch in Options > Language, or force it for a run with `-Dhtf.lang=bn`. Add or fix translations in
`src/main/resources/lang/bn.txt`. To find English text that still needs a translation, run any capture with
`-Dhtf.lang=bn -Dhtf.i18n.missing=/tmp/missing.txt` and read the file afterwards. `I18nTest` checks every entry.

### Screenshots

To see every screen without a GPU, use the dev capture tool under a virtual display (`-Dhtf.capture.set=menus|game|quick|dry|all`,
`dry` is the drought scenario):

```bash
LIBGL_ALWAYS_SOFTWARE=1 xvfb-run -a -s "-screen 0 1280x720x24" \
  java -Dhtf.capture=/tmp/shots -cp target/agrocene.jar org.anthropocene.htf.Main --width 960 --height 540
```

## Calibration

The water model constants are in `sim/Config.java`. They must be tuned against the real data once it is downloaded
(see `../docs/DATA.md`); the web build's `node scripts/calibrate.mjs` does the same search.
